# 《卦锻》（暂定名）核心玩法策划文档

> 版本：v0.2.2（规划草案）｜状态：待评审｜适用：核心玩法立项 / 可玩原型范围
> 一句话概念：一款以《周易》八卦为「卡牌语言」、把 **64 卦当作牌型** 的 Roguelike 卡牌构筑游戏。玩家每回合取两张八卦牌合成一个卦象，用来附魔武器/催动功法攻击敌人；再用法宝与符箓搭出可叠加的伤害引擎，在一局局「修行历劫」中滚雪球式变强。

## 1. 设计概述

### 1.1 设计支柱（Pillars）

- **P1 卦象即牌型**：扑克牌型换成「卦象」。两张八卦牌按「内卦→外卦」合成一卦，卦名来自真实 64 卦（如 火雷噬嗑、地天泰），效果与卦名/卦义一致。玩家记忆的不是规则，是「哪些卦厉害、怎么凑」。
- **P2 顺序即意义**：同一对牌，正反组合是两个不同的卦（泰/否、既济/未济），效果方向相反。这给出小丑牌没有的决策轴：**这一手怎么摆**。先看局势再决定内外，是核心 skill expression。
- **P3 五行是独立数值轴**：攻击五行、敌人五行、法宝五行构成克制/相生网络，引导「配牌→配法宝」的构筑方向，避免 64 卦退化成纯数值堆。
- **P4 由 8 生 64 的低成本高深度**：8 种八卦牌、两张成卦、统一生成规则产出 64 个具名效果；深度来自组合与构筑，不来自内容堆量。
- **P5 明确信息下的爽快数字**：出牌前可预览「将组成什么卦 / 效果 / 预估伤害」，敌人意图可见；伤害数字大而清晰，节奏快、挫败感低。

### 1.2 差异化（为什么不是换皮小丑牌）

1. 小丑牌中「同花 vs 顺子」只是强度差异；本作同一对牌正反组合是**意义相反**的卦（泰=通、否=塞），玩家必须「因敌制宜」地摆牌。
2. 五行克制给「选哪张牌」之外的**第二层选择**：不是所有高倍率卦都适用，要看敌人属性与本命法宝。
3. 附魔使决策跨回合：局部最优（本手伤害）与全局最优（留下什么附魔/状态）可能冲突。
4. 中式志怪题材自带图鉴收集、命名美感与记忆钩子（卦名本身好听、好记、有画面）。

### 1.3 目标玩家与平台
- 喜欢 Balatro / 构筑类 roguelike 的玩家；对东方玄学题材好奇的泛卡牌玩家
- 平台：PC 先行（键鼠 + 手柄），美术与 UI 不做移动端妥协
- 单局 30–45 分钟；一局结束有明确结算，适合「再来一局」

## 2. 核心循环

### 2.1 宏观循环（一局）

```
选择道途(起始牌堆倾向/初始法宝)
        │
   ┌────▼────┐    ┌──────────┐
   │修行历劫│◄───│ 坊市/奇遇 │  （局内商店与随机事件）
   │ 约9战   │    └──────────┘
   └────┬────┘
        ▼
  渡劫（Boss·规则改造）→ 通关或败退
        ▼
   结算：获得「道行」（局外货币）＋ 图鉴解锁
        ▼
   局外成长：解锁新法宝/符箓/武器/道途/难度（天劫）
```

### 2.2 微观循环（一场战斗）

```
玩家回合：摸牌至手牌上限 → 消耗灵力出 1~N 手
   每手：选【内卦(下)】→ 选【外卦(上)】→ 合成卦象
        → ① 触发卦象效果 ② 附魔/状态写入 ③ 按公式结算攻击
   ↓
敌人回合：按「意图」行动（攻击 / 上状态 / 改变环境卦 / 召唤）
   ↓
循环，直到敌方 HP=0（胜）或玩家 HP=0（负）
```

### 2.3 一局节奏
- **前期（第 1–3 战）**：牌堆以基础八卦牌为主，先学会「凑有效卦」；敌人数值低，容错高。
- **中期（第 4–7 战）**：法宝与符箓开始形成乘区；敌人出现五行属性与特殊行为，开始「因敌配卦」。
- **后期（第 8 战+）**：构筑成型，追求一回合内多手连发与巨额数字；渡劫规则开始限制构筑。
- 设计目标：每局都能体验到至少一次「构筑成型后的爽快爆发」，即使该局最终失败。

### 2.4 修行境界结构（局内进度）

一局采用「3 境界 × 3 关」的线性推进：每境界前两关为守关战，第三关为**渡劫（Boss）**；渡劫胜利即晋升下一境界，失败则本局结束（保留图鉴与少量道行）。

| 境界 | 守关一 | 守关二 | 渡劫（Boss） | 渡劫结果 |
|------|--------|--------|--------------|----------|
| 炼气期 | 炼气一层（普通） | 炼气圆满（精英） | 筑基渡劫 | 晋升筑基 |
| 筑基期 | 筑基初期（普通） | 筑基后期（精英） | 金丹渡劫 | 晋升金丹 |
| 金丹期 | 金丹初期（普通） | 金丹后期（精英） | 元婴渡劫 | 晋升元婴 |

- **顺序推进**：境界只能顺序突破，当前关未通过则下一关保持锁定，不能跳关。
- **渡劫 = Boss 战**：渡劫关附带规则改造（见 §5.5），是每境界的主题难题；结算统一提示「渡劫成功 · 晋升××」。
- **长线扩展**：高天劫难度 / 无尽模式可继续接「化神 → 炼虚 → 合体 → 大乘 → 渡劫飞升」。
- **命名区分**：「渡劫」是局内 Boss 战；「天劫」是局外难度 modifier（见 §6.3），两者不要混用。

### 3.2 五行生克（游戏内规则）

- 五行：金、木、水、火、土（后天八卦归属：乾兑=金，震巽=木，坎=水，离=火，艮坤=土）
- **相克（用于对敌伤害结算）**：金克木、木克土、土克水、水克火、火克金
- **相生（用于自我增益结算）**：金生水、水生木、木生火、火生土、土生金
- v1 系数假设（待 playtest）：克制 ×1.5 ｜ 被克 ×0.67 ｜ 同属性 ×1.0（敌人同属性时改为 ×0.85，鼓励混属性，避免单属性无脑堆）

## 4. 卡牌与核心机制

### 4.1 八卦牌（基础牌）

- **种类**：8 种卦，即 8 个「花色」。没有点数 2~A 的概念，点数由「品级」承担。
- **牌面**：卦符 + 卦名（乾/兑/离/震/巽/坎/艮/坤）+ 品级（1–4 星）+ 卦力 + 可选词缀。
- **品级与卦力（v1 假设）**：1 星=1、2 星=2、3 星=4、4 星=8 卦力。
- **词缀（稀有牌）**：如「先天灵气：打出时本手卦力 ×2」「变爻：视为相邻卦」等，用于在 8 种花色里制造稀有度与构筑钩子。
- **牌堆**：默认 40~52 张，随道途/商店增减；手牌上限 6；每回合抽至上限。

> 为什么保留牌堆而不是「8 种牌随便出」：牌堆让「这手有没有坎卦、要不要为凑泰卦而弃牌」成为决策，保留了小丑牌「凑牌」的乐趣，也放大弃牌/检索类法宝的价值。

### 4.2 出卦：合成 64 卦（核心机制，务必先评审此节）

**操作**：每手消耗 1 灵力 → 选择手中 1 张作为**内卦（下卦）** → 再选 1 张作为**外卦（上卦）** → 合成卦象并结算。只出一张不构成卦象（不可出）。

**卦象 = 下卦行为 × 上卦修饰，卦名取自真实 64 卦（上卦在上、下卦在下）**：

- 效果主体（做什么）：由**下卦**决定（§3.1 内卦行为）
- 效果参数（怎么做/多强）：由**上卦**决定（§3.1 外卦修饰）
- 攻击五行：= 下卦五行（武器亲和可产生加成，见 §4.5）
- 卦名：真实卦名自动给出，作为「效果识别码」与收集钩子

**为什么顺序有意义（示例）**：

| 组合（上/下） | 卦名 | 语义 | v1 效果方向 |
|--------------|------|------|------------|
| 坤 / 乾 | 地天泰 | 天地交泰，通 | 直伤后抽牌 + 回灵力（顺境滚雪球） |
| 乾 / 坤 | 天地否 | 天地不交，塞 | 群攻但高威力、代价大（如本回合不能再出手） |
| 坎 / 离 | 水火既济 | 事已成 | 灼烧 + 冰冻同时结算，稳定强 |
| 离 / 坎 | 火水未济 | 事未成 | 强控制/高收益但带随机或风险 |
| 离 / 震 | 火雷噬嗑 | 咬合而明 | 连击且每段可会心 |
| 震 / 离 | 雷火丰 | 明以动 | 灼烧先额外触发一次再结算 |

**64 卦效果生成规则（成本控制关键）**：
1. 全部 64 卦 = 8 内卦行为 × 8 外卦修饰的矩阵产物，命名与数值都由矩阵行/列决定；
2. 少数「特殊卦」（初版约 8~16 个，如 乾为天、坤为地、泰、否、既济、未济、大有、大壮）配置**唯一卦辞效果**，作为可传播的记忆点；
3. 效果文本自动拼接：「（内卦行为描述）+（外卦修饰描述）」，保证 64 条文案不重复劳动且可本地化；
4. 图鉴按矩阵呈现，玩家看到 8×8 网格，天然理解「还差哪个组合没打出来」。

**示例卦效果（v1 草案）**：

| 卦（上/下） | 效果草案 |
|------------|----------|
| 乾为天 | 至刚：造成巨额单体直伤，倍率全卦最高档 |
| 坤为地 | 厚载：对全体造成伤害，并为玩家生成护盾 |
| 火天大有 | 丰收：造成伤害后本场战斗掉落灵石 +N |
| 天泽履 | 履虎尾：高倍率直伤，但下回合开始受到小额反噬 |
| 雷天大壮 | 大壮：连击次数 +2，本手不可被格挡 |
| 泽水困 | 困：回复 2 灵力但本手伤害减半（用资源换资源） |

### 4.3 法宝（被动构筑位，对标 Joker）

- 槽位：4~5 个；稀有度 5 档：凡品→灵品→玄品→地品→天品。
- 触发句式统一为「条件 → 加成」，保证程序模板化：

| 法宝示例 | 品阶 | 效果草案 |
|----------|------|----------|
| 火德星君令 | 灵品 | 你打出火属性卦象时，本手卦力 ×1.5 |
| 泰卦真解 | 玄品 | 每次合成「泰卦」：抽 1 张并回复 1 灵力 |
| 连山印 | 地品 | 你每回合的第一手：伤害 ×2 |
| 噬嗑牙 | 地品 | 「噬嗑」卦的连击每段附加 1 层灼烧 |
| 阴阳鱼 | 天品 | 每打出 3 个阴卦（兑/离/巽/坤），下个阳卦（乾/震/坎/艮）伤害 ×3 |
| 赑屃镇 | 凡品 | 每场战斗第一次濒死时，保留 1 HP（每局一次） |

- 法宝是构筑的「乘区发动机」，也是局内商店的主要消耗目标。

### 4.4 符箓（一次性消耗品，对标塔罗/星球牌）

| 符箓 | 效果草案 |
|------|----------|
| 逆转符 | 本手可交换内/外卦顺序（把「泰」变成「否」或反之） |
| 变卦符 | 本手将一张牌视为指定八卦（需图鉴解锁该卦） |
| 点灵砂 | 手牌中一张八卦牌品级 +1 |
| 观星符 | 查看牌堆顶 5 张，将其中 1 张加入手牌 |
| 补天丹 | 本回合灵力 +1 |
| 炼器符 | 立即强化武器（见 §4.5） |
| 避水诀 | 本回合免疫敌人施加的水/寒类减益 |
| 替身人偶 | 抵挡一次致命伤害（消耗自身） |
| 招财符 | 立即获得若干灵石 |

### 4.5 武器 / 功法（攻击载体，统一为一个槽位）

- 每个「攻击槽」对应一把**兵器**或一门**功法**，二者共用同一套规则，差异只在攻击模式：

| 载体 | 攻击模式示例 | 定位 |
|------|--------------|------|
| 玄铁重剑 | 单体、低连击、高基础 | 直伤流 |
| 青锋剑诀 | 单体多段 | 连击/叠状态流 |
| 暴雨梨花 | 群体、多段、低基础 | 扩散/群攻流 |
| 玄冰盾诀 | 高防御 + 反击 | 站场/反伤流 |

- 武器属性：**基础力道**（伤害基数）、**攻击模式**（单体/群攻/段数）、**五行亲和**（可选，打出同五行卦象时 +25% 卦力）、**可附魔槽位**（短持续效果的写入上限，v1 = 3）。
- 附魔：每手卦象在结算攻击后，向附魔槽写入「该卦的持续部分」（如灼烧、护盾、易伤、抽牌等），槽满后新附魔顶替最旧的（先入先出），形成「这次留什么、踢什么」的取舍。
- 局内成长：坊市购买/「炼器符」/奇遇可提升武器等级（+基础力道）或附加词缀。

### 4.6 资源与节奏（v1 假设，全部待 playtest）

| 参数 | v1 假设 |
|------|---------|
| 手牌上限 | 6 |
| 灵力上限 / 每回合回复 | 4 / 2（上限 4，回满则溢出） |
| 每手消耗 | 1 灵力，每手出 2 张成 1 卦 |
| 每回合预计出手 | 约 2~3 手（配合抽牌法宝可更多） |
| 法宝槽 / 符箓携带 | 4~5 个 / 上限 5 张 |
| 附魔槽 | 3 |

> 节奏目标：玩家回合 30~60 秒内完成 2~3 次「选牌-预览-出牌」，敌人回合 5~10 秒，单场战斗 2~5 分钟。

## 5. 战斗系统

### 5.1 敌方构成

- **小怪（守关一 / 守关二）**：单五行、行为简单（攻击/防御二选一），教学与铺垫用。
- **精英（守关二）**：双行为轮换、带 1 个专属技能，掉落更优质。
- **Boss（渡劫）**：高 HP + **规则改造**（见 5.5）；渡劫胜利即晋升下一境界，是每境界的主题难题。
- 敌人属性面板：HP、力道、五行、抗性（五行减伤表）、意图（下回合行动预览）、状态列表。
- 意图系统：显示敌人下回合将「攻击 N / 上状态 / 改变环境」，玩家据此决定本手摆什么卦——这是「顺序即意义」的落点。

### 5.2 伤害公式（v1 草案）

```
总伤害 = 基础 × 卦倍率 × 五行系数 × 法宝乘区 × 会心(若触发)

基础     = 武器基础力道 + 本手两张牌卦力之和（词缀在此生效）
卦倍率   = 由上卦「修饰」决定（如 威=×2.0，泽=×0.9 但回灵力……）
五行系数 = 下卦五行 vs 敌人五行：克制×1.5 / 被克×0.67 / 同×1.0(敌人同属性×0.85)
法宝乘区 = (1 + Σ加法加成) × Π乘法加成      ← 模仿小丑牌 mult 结构
会心     = 「明/离」修饰等提供，基础 ×1.5~×3
```

> 数值哲学：基础与卦力负责「线性增长」，法宝负责「指数增长」；法宝总数与灵力上限构成天然膨胀刹车，防止小丑牌后期常见的万亿级失控。

### 5.3 五行结算示例
- 敌方为木属性妖物（弱金、抗火）。
- 玩家打出「火雷噬嗑」（下震=木属性连击）→ 木 vs 木：×1.0；连击次数多但单段低。
- 若改出「泽天夬」（下乾=金直伤）→ 金克木 ×1.5，直伤吃满克制 → 玩家学会「先看敌人五行再决定内卦」。

### 5.4 状态效果（v1 列表，宁少勿多）

| 状态 | 效果 |
|------|------|
| 灼烧 | 回合结束受到层数伤害，层数 -1 |
| 寒滞 | 敌人下回合行动被跳过或减速（渡劫 Boss 免疫部分层数） |
| 易伤 | 受到伤害 +25%/层 |
| 虚弱 | 造成的伤害 -25%/层 |
| 护盾 | 吸收伤害，先于 HP 结算 |
| 破甲 | 无视敌人 N 点防御/抗性 |

### 5.5 渡劫规则改造（Boss，对标小丑牌 Boss Blind，示例池）

| 渡劫 Boss | 规则改造 |
|------|----------|
| 玄冥水君 | 每回合敌人先行动；你打出的卦象五行视为水 |
| 乱序道人 | 你出牌时内/外卦判定随机颠倒（预览仍显示实际卦名） |
| 离火妖王 | 免疫火属性；每次你打出火卦，本回合灵力 -1 |
| 艮山巨灵 | 护甲极高，只有「破甲/贯穿（巽系）」卦能高效输出 |
| 噬法魔 | 你每回合第一个法宝被禁用（下回合恢复） |
| 镜妖 | 复制你上一个卦象的持续效果施加给你自己 |

> 渡劫胜利后的结算统一提示「渡劫成功 · 晋升××」；失败则本局构筑结束，保留图鉴与少量道行。

## 6. 成长与资源

### 6.1 局内经济
- 货币：**灵石**。来源：战斗胜利、火天大有等资源卦、符箓、奇遇。
- 消耗去向：坊市购买法宝/符箓/武器升级/删牌；删牌价格递增。

### 6.2 坊市与奇遇
- 坊市：3~5 个商品位（法宝 2、符箓 1~2、服务 1，如删牌/炼器），可用「刷新」。
- 奇遇（事件）：给文本分支选择，风险/收益并存；v1 只做少量脚本化事件，不做大文本量。

### 6.3 局外成长与难度
- 局外货币：**道行**，通关/败退都结算（败退少量）。
- 解锁内容（永久）：新武器、新法宝图鉴、新符箓、新道途、更高天劫难度。
- **天劫（难度系统）**：逐级追加 modifier，如「敌人 HP +20%」「商店涨价」「每场战斗禁用一种八卦」「敌人意图隐藏」等。
- **命名区分**：关卡内的 Boss 战叫「渡劫」，这里的「天劫」是局外难度词条，两者不是同一概念。
- 设计立场：局外只做「解锁选项」，不做「数值变强」（保持每局公平起跑，类似小丑牌），避免 roguelike 变质。

## 7. 内容量规划与制作分期

### 7.1 MVP（可玩原型，验证核心乐趣）
- 八卦牌 8 种 × 品级 1~3 星
- 64 卦全部可合成，其中 16 个精修独特卦辞，其余走模板
- 武器 3 种（直伤/连击/群攻各一）
- 法宝约 20 个、符箓约 8 个
- 敌人：小怪 6、精英 3、渡劫 Boss 3（筑基 / 金丹 / 元婴渡劫）
- 单局 3 境界（炼气 / 筑基 / 金丹）约 9 场战斗（含 3 次渡劫）+ 2 次坊市 + 1 奇遇
- 图鉴（卦象网格 + 效果预览）、基础局外解锁 3 档
- 存档：1 个自动存档槽，支持局内节点与战斗内“玩家尚未行动”快照继续
- **MVP 验收标准**：不教学也能在 2 局内理解「内/外卦、五行克制、法宝乘区」；第 3 境界的「元婴渡劫」前能稳定形成一套成型构筑；单局 30~40 分钟无严重卡顿或卡手死局。

### 7.2 后续阶段
- **阶段 2（内容补全）**：64 卦精修化、法宝联动词缀、渡劫 Boss 池扩到 6+、天劫 1~8、更多奇遇
- **阶段 3（长线）**：无尽模式（卦象越来越强的循环）、每日挑战/种子、全图鉴收集奖励、新牌型扩展（见 7.3 备注）

### 7.3 内容成本控制与未来扩展位
- 核心成本在「64 卦文案与特效」→ 用矩阵模板 + 特效复用（灼烧/连击/护盾等一套表现层）。
- 预留扩展位：变爻机制（本卦/之卦，一张牌出两次效果）、天干/地支配对（60 甲子作为高难牌型）、敌人五行双属性、多武器切换。

## 8. 风险与对策

| 风险 | 对策 |
|------|------|
| 玩家对 64 卦 + 五行感到陌生、门槛高 | 图鉴网格可视化、出牌前完整预览、新手局只开放 8 卦中的 4 种并逐步解锁、卦名旁给白话效果 |
| 只有 8 种牌 → 组合单调 | 品级/词缀/特殊牌制造稀有度；变爻与天干扩展位已在路线图 |
| 内/外顺序反直觉 | UI 强引导：先选内卦（下方亮起），实时预览「将合成 ××卦」，结算动画强调上下结构 |
| 附魔/状态堆叠数值爆炸 | 附魔槽先入先出 + 灵力上限限制手数；法宝稀有度与乘区结构做膨胀刹车 |
| 64 独特效果内容成本过高 | 模板矩阵（§4.2）是默认方案，独特卦辞只给 8~16 个记忆点卦 |
| 玄学题材敏感/被质疑不严谨 | 明确定位为「架空演绎」，不涉及占卜功能与迷信引导，文案以「好玩优先、卦义神似即可」为准 |

## 9. 待验证问题清单（Playtest 假设）

1. 两张牌成卦是否决策太轻？是否需要「三张成卦（天地人三才）」或「允许叠变爻」加深？
2. 每回合 2~3 手是否足够爽？灵力模型（回 2/上限 4）是否卡手？
3. 五行克制 ±50% 是否过于主导？要不要压到 ±30% 让构筑更自由？
4. 附魔先入先出是否有趣？还是应该允许玩家主动选择踢掉哪个附魔？
5. 64 卦矩阵里是否存在「明显废卦」或「唯一最优卦」？目标：任意五行/任意武器都有 ≥2 条可行构筑路线。
6. 局外只解锁不变强，是否足够驱动「再来一局」？需要多少内容解锁量？
7. 渡劫规则改造哪些「有趣但公平」、哪些过于惩罚？
