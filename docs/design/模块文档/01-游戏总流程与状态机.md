# 01 · 游戏总流程与状态机

> 版本：v0.2.2 ｜ 依赖：02、03、08、09、10、13 ｜ 总纲：`../核心玩法策划.md` §2

## 1. 模块目标

定义玩家从**启动游戏**到**完成一局、回到主界面、开启下一局**的完整状态流转，明确每个状态的进入条件、主要 UI、退出条件和异常处理。

本模块只描述“页面/状态级”流程；战斗内的回合细节见 `03-战斗流程.md`，一局内的境界推进见 `02-单局历劫流程.md`。

---

## 2. 顶层状态机

| 状态 ID | 状态 | 进入条件 | 主要 UI | 退出条件 |
|---------|------|----------|---------|----------|
| `BOOT` | 启动/加载 | 游戏启动 | 加载页 | 资源就绪 → `MAIN_MENU`（按存档状态显示“继续游戏”） |
| `MAIN_MENU` | 主界面 | 加载完成 / 一局结束 | 继续游戏（有存档时）、开始修行、图鉴、设置、退出 | 点击“继续游戏”→ 恢复局内节点；点击“开始修行”→ `RUN_SETUP`；点击图鉴→ `CODEX` |
| `CODEX` | 图鉴 | 主界面点击图鉴 | 8×8 卦象网格、详情面板 | 返回 → `MAIN_MENU` |
| `SETTINGS` | 设置 | 主界面点击设置 | 音量/语言/按键/画面 | 返回 → `MAIN_MENU` |
| `RUN_SETUP` | 开局准备 | 开始修行 | 选择道途、初始武器/功法、查看初始资源 | 确认 → `RUN_MAP`；返回 → `MAIN_MENU` |
| `RUN_MAP` | 修行路线 | 开局确认 / 战斗结算后 | 九关路线、当前关详情、开始战斗 | 点击开始战斗 → `BATTLE`；进入坊市 → `SHOP` |
| `BATTLE` | 战斗 | 路线页点击开始战斗 | 战斗界面（见 03/10） | 战斗结束 → `BATTLE_RESULT` |
| `BATTLE_RESULT` | 战斗结算 | 敌人或玩家 HP ≤ 0 | 胜利/失败结算、奖励列表 | 胜利 → `RUN_MAP`；失败 → `RUN_RESULT` |
| `SHOP` | 坊市 | 境界间 / 路线页进入 | 商品位、刷新、服务 | 离开 → `RUN_MAP` |
| `EVENT` | 奇遇 | 路线节点触发 | 事件文本、选项、结果 | 结算 → `RUN_MAP` |
| `REALM_PROMOTION` | 境界晋升 | 渡劫胜利 | 晋升动画、境界奖励 | 确认 → `RUN_MAP`（下一境界） |
| `RUN_RESULT` | 一局结算 | 通关 / 失败 / 放弃 | 道行结算、解锁提示 | 确认 → `META_PROGRESS` |
| `META_PROGRESS` | 局外成长 | 一局结算后 | 解锁武器/法宝/符箓/道途/天劫 | 返回 → `MAIN_MENU` |

## 3. 页面流转图

```
BOOT
 │
 ▼
MAIN_MENU ───────────────► CODEX / SETTINGS
 │  │                            │
 │  └─ 继续游戏 ────────────────► 恢复 RUN_MAP / SHOP / EVENT / BATTLE
 │ 开始修行                       │ 返回
 ▼                               ▼
RUN_SETUP ──确认──► RUN_MAP ◄──────────────┐
                      │  ▲                 │
                      │  │ 战斗胜利/坊市离开 │
                      ▼  │                 │
                   BATTLE ──► BATTLE_RESULT┘
                      │            │
                      │            │ 失败
                      │            ▼
                      │        RUN_RESULT
                      │            │
                      ▼            ▼
                   SHOP / EVENT   META_PROGRESS
                      │            │
                      └──► RUN_MAP │

```

> `RUN_MAP` 是局内“中枢页面”：战斗、坊市、奇遇、境界晋升都回到它，再进入下一关。

## 4. 开局准备流程（`RUN_SETUP`）

1. **选择道途**：决定起始牌堆倾向与初始被动（示例：火行道途 → 离卦/火卦出现率提高）。
2. **选择初始武器/功法**：决定基础力道与攻击模式（见 `05-武器功法与附魔.md`）。
3. **查看初始资源**：初始灵石、初始符箓、已解锁法宝池。
4. **确认开局**：进入 `RUN_MAP`，从炼气期第一关开始。

> 开局准备阶段不进入战斗；确认后本局构筑锁定（局内可通过坊市/奖励调整）。

---

## 5. 局内主循环

```
RUN_MAP（查看当前关）
   │
   ├─ 开始战斗 → BATTLE → BATTLE_RESULT（胜利）
   │                         │
   │                         ├─ 普通/精英关 → 领取奖励 → RUN_MAP
   │                         └─ 渡劫关 → REALM_PROMOTION → RUN_MAP（下一境界）
   │
   ├─ 坊市（境界间） → SHOP → RUN_MAP
   └─ 奇遇（固定节点） → EVENT → RUN_MAP
```

- 关卡只能**顺序推进**：当前关未通过，下一关保持锁定。
- 战斗胜利后先结算奖励，再回到路线页；不自动进入下一关，玩家可先查看状态/进入坊市。
- 渡劫胜利后进入晋升流程；渡劫失败直接进入 `RUN_RESULT`。

---

## 6. 局外循环

```
RUN_RESULT（通关 / 失败 / 放弃）
   │
   ▼
META_PROGRESS：结算道行、解锁内容、查看图鉴进度
   │
   ▼
MAIN_MENU：开始下一局（可选择更高天劫）
```

- 局外只做“解锁选项”，不做永久数值变强（保持每局公平起跑）。
- 失败也结算少量道行；图鉴进度永久保留。
- 天劫难度逐级解锁，具体词条见 `09-修行境界与局外成长.md`。

## 7. 暂停、退出与存档

| 场景 | 规则 |
|------|------|
| 战斗中暂停 | 可查看牌堆、法宝、符箓、图鉴；不能改变已出的牌 |
| 战斗中退出到主界面 | 保存当前战斗快照后返回主界面；继续游戏恢复到**本回合玩家行动阶段开始** |
| 战斗中断线/崩溃 | 读取最近一次**玩家回合开始快照**；未保存的操作中间态不保留 |
| 玩家已操作但未结束回合时退出 | 回滚到本回合开始快照；已执行的出卦/弃牌/符箓不保留 |
| 路线页退出 | 保留本局进度，可下次继续 |
| 坊市/奇遇中退出 | 保留本局进度，恢复到对应节点 |
| 局外退出 | 无影响，局外数据永久保存 |

### 存档点

- 开局确认后
- 每场战斗初始化后
- 每个玩家回合开始（回合开始效果结算完成、玩家尚未操作）
- 战斗胜利结算后
- 坊市购买/刷新后
- 奇遇结算后
- 境界晋升后
- 一局结束

> `[已定]` 战斗内按“玩家回合开始”写入战斗快照；继续游戏后不重掷手牌、抽牌堆顺序、敌人意图等随机结果。完整字段与边界见 `13-存档与继续游戏需求.md`。

## 8. 异常与边界情况

| 情况 | 处理 |
|------|------|
| 战斗中玩家 HP ≤ 0 | 进入失败结算；本局结束 |
| 渡劫失败 | 本局结束；保留图鉴与少量道行 |
| 玩家主动放弃 | 二次确认；本局结束；按失败结算 |
| 通关（元婴渡劫胜利） | 进入通关结算；解锁更高天劫 |
| 存档损坏/版本不兼容 | 回到主界面并提示；局外数据尽量保留 |
| 资源加载失败 | 回到 `BOOT`，提供重试 |
