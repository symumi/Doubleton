# 02 · 单局历劫流程

> 版本：v0.2 ｜ 依赖：03 战斗、07 敌人/渡劫、08 坊市、09 境界 ｜ 总纲：`../核心玩法策划.md` §2.4

## 1. 模块目标

定义“一局游戏”（修行历劫）的完整流程：从炼气期开局，到三次渡劫，再到通关或失败结算。明确每关的进入条件、奖励、坊市/奇遇插入点与失败规则。

---

## 2. 一局结构

- 一局 = **3 境界 × 3 关 = 9 场战斗**，其中 **3 场是渡劫（Boss）**。
- 目标单局时长：**30–45 分钟** `[v1假设]`。
- 顺序推进：当前关未通过，下一关保持锁定，**不可跳关**。

| 境界 | 守关一 | 守关二 | 渡劫（Boss） | 渡劫结果 |
|------|--------|--------|--------------|----------|
| 炼气期 | 炼气一层（普通） | 炼气圆满（精英） | 筑基渡劫 | 晋升筑基 |
| 筑基期 | 筑基初期（普通） | 筑基后期（精英） | 金丹渡劫 | 晋升金丹 |
| 金丹期 | 金丹初期（普通） | 金丹后期（精英） | 元婴渡劫 | 晋升元婴 |

> 本局通关时晋升元婴；元婴期及更高境界（化神 → 炼虚 → 合体 → 大乘 → 渡劫飞升）作为长线扩展 / 高天劫内容（见 `09-修行境界与局外成长.md`）。

   ├─ 第5关：筑基后期（精英）──► 奇遇 ①

## 4. 单关流程

```
RUN_MAP 路线页
   │ 查看当前关：敌人、五行、意图、奖励、难度
   ▼
开始战斗 → BATTLE
   │
   ├─ 胜利 → BATTLE_RESULT → 领取奖励 → 回到 RUN_MAP
   │           │
   │           ├─ 普通/精英关：解锁下一关
   │           └─ 渡劫关：REALM_PROMOTION → 晋升下一境界
   │
   └─ 失败 → RUN_RESULT（本局结束）
```

- 战斗胜利后**不自动**进入下一关；玩家可在路线页查看状态、进入坊市/奇遇。
- 路线页只显示当前关与已通关/未解锁状态；已通关的关不可重复挑战。
- 每个关卡的敌人、五行、意图、奖励在进入战斗前可见（Boss 的规则改造也提前显示）。

---

## 5. 坊市与奇遇插入点

一局固定 **2 次坊市 + 1 次奇遇** `[v1假设]`：

| 节点 | 类型 | 触发时机 | 说明 |
|------|------|----------|------|
| 坊市 ① | 商店 | 筑基渡劫胜利、晋升筑基后 | 补充法宝/符箓，强化武器 |
| 奇遇 ① | 事件 | 筑基后期（第5关）胜利后 | 一次文本抉择，风险/收益并存 |
| 坊市 ② | 商店 | 金丹渡劫胜利、晋升金丹后 | 最终调整构筑，准备元婴渡劫 |

- 坊市/奇遇结束后回到路线页，再进入下一关。
- 坊市/奇遇不消耗关卡次数，不改变“顺序推进”。
- 坊市/奇遇的详细规则见 `08-坊市经济与奇遇.md`。

---

## 6. 奖励结构 `[v1假设]`

| 关卡类型 | 灵石 | 其他奖励 |
|----------|------|----------|
| 普通守关 | 25–35 | 小概率符箓 |
| 精英守关 | 35–50 | 概率符箓、概率法宝 |
| 渡劫 Boss | 60–80 | 必得法宝或稀有符箓 + 晋升 |

- 奖励在 `BATTLE_RESULT` 结算；玩家确认后进入路线页。
- 资源卦（如火天大有）可在战斗内额外产出灵石。
- 渡劫奖励与晋升奖励分开：渡劫奖励是战斗掉落，晋升奖励是境界奖励（见 09）。

---

## 7. 失败、放弃与重开

| 情况 | 处理 |
|------|------|
| 普通/精英关失败 | 本局结束 → 失败结算；保留图鉴与少量道行 |
| 渡劫失败 | 本局结束 → 失败结算；不晋升，境界进度重置到本局起点 |
| 主动放弃 | 二次确认 → 失败结算 |
| 通关 | 元婴渡劫胜利 → 通关结算 → 解锁更高天劫 |
| 重开一局 | 回到 `RUN_SETUP`；局外解锁保留 |

> 本局内没有“复活”与“重试当前关”；失败即结束本局，保持 roguelike 的决策重量。

---

## 8. 局内节奏

| 阶段 | 关卡 | 体验目标 |
|------|------|----------|
| 前期 | 第1–3关 | 学会内/外卦、五行克制；容错高，构筑未成型 |
| 中期 | 第4–6关 | 法宝/符箓开始形成乘区；因敌配卦 |
| 后期 | 第7–9关 | 构筑成型，追求多手连发；元婴渡劫限制构筑 |

- 每局至少让玩家体验一次“构筑成型后的爆发”，即使最终失败。
- 渡劫前应给玩家一次坊市/调整机会，避免“无准备硬碰 Boss”。

## 10. 待验证问题

1. 一局 9 场战斗是否过长？是否需要根据难度动态减少普通关？
2. 坊市固定 2 次是否足够？是否应该允许每场战斗后付费刷新？
3. 奇遇固定 1 次是否太可预测？是否需要随机节点池？
4. 渡劫失败是否应该保留“本境界已获得的奖励”，还是全部失去？
5. 普通/精英/渡劫的奖励曲线是否需要更陡，才能让玩家感到渡劫的仪式感？
