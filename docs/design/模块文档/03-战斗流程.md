# 03 · 战斗流程

> 版本：v0.2 ｜ 依赖：04 卦象、05 武器附魔、06 法宝符箓、07 敌人 ｜ 总纲：`../核心玩法策划.md` §2.2 / §5

## 1. 模块目标

定义一场战斗从初始化到胜负判定的完整回合流程，明确出卦结算顺序、伤害公式、状态结算与边界情况。

一场战斗由 `01-游戏总流程与状态机.md` 的 `BATTLE` 状态承载，结束后进入 `BATTLE_RESULT`。

---

## 2. 战斗初始化

| 步骤 | 内容 |
|------|------|
| 1 | 洗牌：将本局牌组洗入抽牌堆 |
| 2 | 抽初始手牌：抽至手牌上限 **6** |
| 3 | 灵力初始化：灵力 = 上限 **4** `[v1假设]` |
| 4 | 玩家状态初始化：护盾归零；战斗内状态清空（跨战斗状态按法宝/符箓规则处理） |
| 5 | 敌人生成：读取当前关配置（HP、五行、意图、规则改造） |
| 6 | 敌人意图生成：显示下回合行动预览 |

> 战斗开始前的状态：上一场战斗的护盾不保留；灼烧/易伤等战斗内状态清空；法宝的“每场战斗一次”计数器重置。

## 3. 回合流程

### 3.1 玩家回合开始

1. 灵力 +2（不超过上限 4）`[v1假设]`。
2. 触发“回合开始”类法宝/状态。
3. 抽牌至手牌上限 6。
4. 显示敌人当前意图。

### 3.2 玩家行动

玩家可重复执行以下行动，直到主动结束回合或资源耗尽：

| 行动 | 条件 | 消耗 | 结果 |
|------|------|------|------|
| 出卦 | 灵力 ≥ 1 且手牌 ≥ 2 | 灵力 1 + 2 张手牌 | 合成卦象并结算 |
| 弃牌换牌 | 每回合弃牌次数 > 0 | 弃牌次数 1 | 弃 N 张，抽 N 张 |
| 使用符箓 | 符箓可用、时机合法 | 符箓 1 张 | 结算符箓效果 |
| 结束回合 | 任意时刻 | — | 进入敌方回合 |

> `[v1假设]` 每回合弃牌次数 3 次；弃牌换牌不可在出卦动画结算中执行。

### 3.3 出卦结算顺序（核心）

出卦必须严格按以下顺序结算，避免“先加伤还是先上易伤”的歧义：

1. **校验**：灵力 ≥ 1、手牌 ≥ 2、选择合法。
2. **选内卦（下卦）**：决定卦象行为与攻击五行。
3. **选外卦（上卦）**：决定卦象修饰。
4. **合成卦象**：确定卦名、五行、基础效果、附魔效果。
5. **计算基础伤害**：武器基础力道 + 本手两张牌的卦力之和。
6. **应用乘区**：卦倍率 → 五行系数 → 法宝乘区 → 会心。
7. **结算卦象效果**：灼烧、护盾、抽牌、回灵、易伤等。
8. **写入附魔**：将卦象的短持续部分写入附魔槽（槽满按先入先出）。
9. **触发法宝**：按法宝的触发条件与顺序结算。
10. **结算敌人受伤/死亡**：护盾 → HP；若死亡则立即进入胜利判定。
11. **消耗灵力 1**，本次出卦结束。

> 若敌人已在本手第 10 步死亡，第 11 步仍会消耗灵力；本手后续效果不再触发（除非法宝明确写“击杀后触发”）。

## 4. 伤害公式与结算顺序

```
总伤害 = 基础 × 卦倍率 × 五行系数 × 法宝乘区 × 会心（若触发）

基础     = 武器基础力道 + 本手两张牌卦力之和
卦倍率   = 外卦“修饰”决定（如威 ×2.0；特殊卦可覆盖）
五行系数 = 内卦五行 vs 敌人五行：克制 ×1.5 / 被克 ×0.67 / 同属 ×1.0
           （敌人与攻击同属性时按 ×0.85 处理）
法宝乘区 = (1 + Σ加法加成) × Π乘法加成
会心     = “明/离”修饰等提供，基础 ×1.5 ~ ×3
```

### 结算顺序

```
基础伤害
  → 卦倍率
  → 五行系数
  → 法宝乘区
  → 会心
  → 敌人护甲/减伤
  → 敌人护盾
  → 敌人 HP
```

- 易伤、虚弱等状态在“乘区”阶段参与计算（易伤 +25%/层，虚弱 -25%/层）。
- 破甲只影响敌人护甲/减伤，不影响五行系数。
- 护盾优先于 HP 扣除。

---

## 5. 敌方回合

1. 敌人执行当前意图（攻击 / 上状态 / 改变环境 / 召唤 / 蓄力）。
2. 结算敌人身上的持续状态（灼烧等）——`[待验证]` 灼烧在敌人行动前还是行动后结算。
3. 结算玩家受伤：护盾 → HP。
4. 敌人生成下回合意图。
5. 回到玩家回合（若双方均未倒下）。

---

## 6. 胜负判定

```
敌人 HP ≤ 0 ?
  ├─ 是 → 战斗胜利 → BATTLE_RESULT（胜利）
  └─ 否 → 玩家 HP ≤ 0 ?
            ├─ 是 → 战斗失败 → RUN_RESULT（失败）
            └─ 否 → 下一回合 → 玩家回合开始
```

- 胜利：结算奖励；渡劫战额外触发晋升流程。
- 失败：本局结束；保留图鉴与少量道行。
- 同时死亡：按“玩家失败”处理 `[待验证]`，避免出现空血胜利。

## 7. 状态效果 `[v1假设]`

| 状态 | 效果 | 叠加 | 持续 |
|------|------|------|------|
| 灼烧 | 回合结束受到层数伤害 | 层数 | 战斗内，每回合 -1 |
| 寒滞 | 下回合行动被跳过/减速 | 层数 | 1 回合；渡劫 Boss 部分免疫 |
| 易伤 | 受到伤害 +25%/层 | 层数 | 战斗内 |
| 虚弱 | 造成伤害 -25%/层 | 层数 | 战斗内 |
| 护盾 | 吸收伤害，先于 HP | 数值 | 战斗内，不跨战斗 |
| 破甲 | 无视敌人 N 点护甲/减伤 | 数值 | 本次伤害 |

## 8. 资源与节奏 `[v1假设]`

| 参数 | 默认值 |
|------|--------|
| 手牌上限 | 6 |
| 灵力上限 / 每回合回复 | 4 / 2 |
| 每手消耗 | 1 灵力 + 2 张手牌 |
| 每回合预计出手 | 2–3 手 |
| 每回合弃牌次数 | 3 |
| 附魔槽 | 3 |
| 单场战斗时长 | 2–5 分钟 |

## 9. 边界与异常

| 情况 | 处理 |
|------|------|
| 手牌 < 2 | 不能出卦；可弃牌/用符箓/结束回合 |
| 灵力 = 0 | 不能出卦；可弃牌/用符箓/结束回合 |
| 抽牌堆空 | 将弃牌堆洗回抽牌堆，再抽牌 |
| 敌人被灼烧/反伤杀死 | 立即进入胜利判定 |
| 多个法宝同时触发 | 按法宝槽位从左到右结算 `[v1假设]` |
| 渡劫 Boss 规则与法宝冲突 | 渡劫 Boss 规则优先；冲突时给出明确提示 |
| 出卦前取消选择 | 允许，不消耗资源 |
| 出卦结算后撤销 | 不允许 |

## 11. 待验证问题

1. 每回合回 2 灵力、上限 4 是否会导致“要么卡手、要么爆发过强”？
2. 出卦结算顺序中，“卦象效果”与“法宝触发”谁先谁后最直观？
3. 灼烧等持续伤害应在敌人行动前还是行动后结算？
4. 同时死亡是否应该判定为平局/玩家失败？
5. 多个法宝触发顺序是否应该可配置，而不是固定从左到右？
