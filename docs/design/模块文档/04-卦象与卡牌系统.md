# 04 · 卦象与卡牌系统

> 版本：v0.2 ｜ 依赖：03 战斗、05 武器附魔、10 图鉴、12 数据字典 ｜ 总纲：`../核心玩法策划.md` §3 / §4

## 1. 模块目标

定义本作的核心“牌型系统”：八卦牌、牌堆/手牌、内卦/外卦、64 卦合成、卦力/品级/词缀、熟练度与图鉴收集。

一句话：**8 种八卦牌 × 两张成卦 = 64 卦牌型**；下卦定行为与五行，上卦定修饰，顺序决定卦义。

---

## 2. 核心概念

| 概念 | 定义 |
|------|------|
| 八卦牌 | 牌堆中的基础牌，共 8 种卦；有品级、卦力、可选词缀 |
| 内卦 / 下卦 | 先选、摆在下方的牌；决定卦象行为与攻击五行 |
| 外卦 / 上卦 | 后选、摆在上方的牌；决定卦象修饰 |
| 卦象 | 内 + 外合成的一个 64 卦，即本作“牌型” |
| 卦力 | 牌提供的伤害基数，受品级影响 |
| 品级 | 1–4 星，决定卦力与稀有度 |
| 词缀 | 稀有牌上的额外效果（如“先天灵气”“变爻”） |
| 熟练度 / 精通 | 单个卦象的使用成长；精通提供额外加成 |

---

## 3. 八卦牌基础设定

游戏内以**后天八卦五行**为唯一权威，避免多套体系冲突。

| 卦 | 卦符 | 卦德 | 五行 | 阴阳 | 内卦行为（下卦） | 外卦修饰（上卦） |
|----|------|------|------|------|------------------|------------------|
| 乾 | ☰ | 健 | 金 | 阳 | 至刚直伤：单体高倍率 | 威：本手伤害倍率大幅提升 |
| 兑 | ☱ | 说(悦) | 金 | 阴 | 夺灵：造成伤害并回复 | 泽：回复灵力 / 降低费用 |
| 离 | ☲ | 丽(明) | 火 | 阴 | 灼烧：施加持续伤害 | 明：本手可会心 |
| 震 | ☳ | 动 | 木 | 阳 | 连击：多次较小伤害 | 迅：追加一次触发 / 先手 |
| 巽 | ☴ | 入 | 木 | 阴 | 破甲贯穿：无视部分防御 | 散：扩散到多个目标 |
| 坎 | ☵ | 陷(险) | 水 | 阳 | 寒滞：冰冻 / 减益控制 | 渊：延长持续 / 加深控制 |
| 艮 | ☶ | 止 | 土 | 阳 | 止御：护盾 / 格挡 | 定：必中 / 去除随机性 |
| 坤 | ☷ | 顺(载) | 土 | 阴 | 载物：群攻 / 承伤 | 载：附带资源与续航 |

> 阴阳归属用于法宝联动与部分特殊卦效果；不作为基础伤害的独立乘区。

## 4. 牌堆与手牌

| 项目 | v1 默认值 | 说明 |
|------|-----------|------|
| 初始牌堆 | 40–52 张 | 随道途/开局选择变化 |
| 手牌上限 | 6 | 每回合抽至上限 |
| 每手出牌 | 2 张 | 1 张内卦 + 1 张外卦 |
| 弃牌堆 | 独立 | 抽牌堆空时洗回 |
| 初始牌堆构成 | 8 卦大致均衡 | 道途会提高某五行/卦的占比 |

### 抽牌与弃牌

1. 每回合开始抽至手牌上限 6。
2. 出卦消耗 2 张牌，进入弃牌堆。
3. 弃牌换牌：弃 N 张，抽 N 张；每回合限 3 次 `[v1假设]`。
4. 抽牌堆空：将弃牌堆洗回抽牌堆，再抽牌。

> 保留“牌堆”而不是“8 种牌随便出”，是为了保留凑牌/弃牌的决策乐趣。

---

## 5. 出卦规则（核心）

```
每手消耗 1 灵力
  → 选择 1 张作为内卦（下卦）
  → 选择 1 张作为外卦（上卦）
  → 合成卦象并结算
```

- 只出 1 张**不构成卦象**，不可出。
- 顺序有意义：同一对牌，正反组合是两个不同的卦。
- 示例：上坤下乾 = 地天泰（通）；上乾下坤 = 天地否（塞）。
- 示例：上坎下离 = 水火既济（成）；上离下坎 = 火水未济（未成）。

## 6. 64 卦生成规则

64 卦 = **8 内卦行为 × 8 外卦修饰** 的矩阵产物，卦名取自真实文王 64 卦。

| 生成层 | 来源 | 作用 |
|--------|------|------|
| 行为 | 下卦（内卦） | 决定“做什么”：直伤/连击/灼烧/护盾/群攻… |
| 修饰 | 上卦（外卦） | 决定“怎么做/多强”：威力/会心/扩散/延长… |
| 攻击五行 | 下卦 | 参与五行克制 |
| 卦名 | 上卦 + 下卦 | 真实 64 卦名，作为效果识别码与收集钩子 |

### 示例

| 上 / 下 | 卦名 | 效果方向 |
|---------|------|----------|
| 乾 / 乾 | 乾为天 | 至刚直伤，倍率最高档 |
| 坤 / 乾 | 地天泰 | 直伤后抽牌 + 回灵力 |
| 乾 / 坤 | 天地否 | 群攻高威力，但有代价 |
| 坎 / 离 | 水火既济 | 灼烧 + 冰冻同时结算，稳定强 |
| 离 / 坎 | 火水未济 | 强控制/高收益，但带风险 |
| 离 / 震 | 火雷噬嗑 | 连击且每段可会心 |
| 震 / 离 | 雷火丰 | 灼烧先额外触发一次再结算 |

### 特殊卦

- 初版约 **8–16 个**特殊卦配置唯一卦辞效果（乾为天、坤为地、泰、否、既济、未济、大有、大壮等）。
- 其余卦象走“行为 + 修饰”模板，效果文本自动拼接，控制内容成本。

## 7. 卦象效果结构

每个卦象由以下部分组成：

| 部分 | 说明 |
|------|------|
| 基础伤害 | 由武器力道 + 两张牌卦力决定 |
| 卦倍率 | 由外卦修饰决定 |
| 五行 | 由内卦决定 |
| 即时效果 | 灼烧、护盾、抽牌、回灵、易伤等 |
| 附魔效果 | 写入附魔槽的短持续部分（见 05） |
| 特殊规则 | 特殊卦的唯一效果，可覆盖模板 |

### 词缀示例

| 词缀 | 效果 |
|------|------|
| 先天灵气 | 打出时本手卦力 ×2 |
| 变爻 | 出牌时视为相邻卦 |

## 9. 熟练度与精通 `[v1假设]`

- 每个卦象记录“使用次数”，累积到阈值提升熟练度。
- 熟练度 5 级为“精通”；精通后该卦象 **伤害 +20%**。
- 图鉴中显示熟练度圆点与精通标记（见 `10-图鉴与UI交互流转.md`）。

## 10. 牌堆构筑

| 来源 | 作用 |
|------|------|
| 开局道途 | 提高某五行/卦的初始占比 |
| 坊市购买 | 获得新牌 / 升级品级 |
| 坊市删牌 | 移除 1 张牌，提高关键卦上手率 |
| 奇遇 | 随机获得/转化牌 |
| 渡劫奖励 | 稀有牌或特殊词缀 |

> 牌堆越精简，凑出目标卦象的概率越高；但删牌价格递增，形成取舍。

---

## 11. 边界与异常

| 情况 | 处理 |
|------|------|
| 手牌 < 2 | 不能出卦；可弃牌/用符箓/结束回合 |
| 抽牌堆空 | 弃牌堆洗回抽牌堆 |
| 同一张牌被重复选择 | 不允许；必须选两张不同手牌 |
| 锁定牌/封印牌 | 不能作为内卦或外卦；UI 明确标识 |
| 变爻词缀 | 合成时按玩家选择的“视为卦”结算，UI 预览最终卦名 |

## 13. 待验证问题

1. 两张牌成卦是否决策太轻？是否需要“三张成卦（天地人）”或变爻扩展？
2. 8 种牌是否足够支撑 30–45 分钟的构筑深度？
3. 卦力 1/2/4/8 的跨度是否过大？是否需要更平滑的成长？
4. 精通 +20% 是否会挤压其他构筑路线？
5. 词缀数量与强度如何控制，避免“只有某一两张稀有牌值得拿”？
