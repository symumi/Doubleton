# 05 · 武器功法与附魔

> 版本：v0.2 ｜ 依赖：03 战斗、04 卦象、06 法宝 ｜ 总纲：`../核心玩法策划.md` §4.5

## 1. 模块目标

定义玩家的“攻击载体”：武器与功法共用同一个攻击槽，负责提供基础力道与攻击模式；卦象负责五行、倍率与效果；附魔负责短持续的构筑叠加。

---

## 2. 攻击槽

- 玩家每局携带 **1 个攻击槽**：一把兵器或一门功法。
- 武器与功法共用同一套规则，差异只在“攻击模式”与表现。
- 攻击槽提供：
  - **基础力道**：伤害公式的基数；
  - **攻击模式**：单体/群攻/段数；
  - **五行亲和**（可选）：打出同五行卦象时 +25% 卦力 `[v1假设]`；
  - **附魔槽**：3 个，用于写入卦象的短持续效果。

> `[v1假设]` 本局内不可更换武器；后续可通过奇遇/坊市扩展“换武器”能力。

---

## 3. 武器 / 功法示例

| 载体 | 基础力道 | 攻击模式 | 五行亲和 | 定位 |
|------|----------|----------|----------|------|
| 玄铁重剑 | 6 | 单体、低连击 | 无 | 直伤流 |
| 青锋剑诀 | 4 | 单体多段（3 段） | 木 | 连击/叠状态流 |
| 暴雨梨花 | 3 | 群体、多段（2 段 × 全体） | 金 | 扩散/群攻流 |
| 玄冰盾诀 | 5 | 单体 + 反击 | 水 | 站场/反伤流 |

> 基础力道与段数为 v1 假设，具体以战斗原型测试为准。

---

## 4. 攻击模式与卦象行为的叠加

| 攻击模式 | 与卦象行为的叠加规则 |
|----------|----------------------|
| 单体 | 直伤/夺灵/寒滞等单体行为正常结算 |
| 多段 | 连击行为按段数叠加；每段独立计算会心 |
| 群攻 | 群攻行为扩散到所有敌人；单体行为只打主目标 |
| 反击 | 敌方攻击时触发；反击伤害不消耗灵力，不触发“出卦”类法宝 |

> 攻击模式只决定“打谁/打几段”；五行、倍率、效果仍由卦象决定。

---

## 5. 附魔机制

### 写入时机

每手卦象结算后，将卦象的**短持续部分**写入附魔槽：

```
出卦结算
  → 即时效果（伤害/抽牌/回灵/护盾）
  → 附魔写入（短持续效果）
  → 法宝触发
```

### 附魔槽规则

| 规则 | 内容 |
|------|------|
| 槽位数量 | 3 `[v1假设]` |
| 写入顺序 | 槽位满时，新附魔顶替最旧（先入先出） |
| 持续时间 | 短持续：本场战斗 / 1–3 回合（按附魔类型） |
| 叠加规则 | 同名附魔刷新持续时间或叠层（具体按效果定义） |
| 跨战斗 | 附魔不跨战斗保留 `[v1假设]` |

### 附魔类型示例

| 附魔 | 来源卦象（示例） | 效果 |
|------|------------------|------|
| 灼烧 | 离系内卦 | 敌人回合结束受到层数伤害 |
| 护盾 | 艮系内卦 | 获得护盾 |
| 易伤 | 兑/离系组合 | 敌人受到伤害提高 |
| 抽牌 | 泰卦等特殊卦 | 立即或下回合抽牌 |
| 回灵 | 兑/坎系组合 | 回复灵力 |

## 6. 武器成长

| 来源 | 效果 |
|------|------|
| 坊市“炼器”服务 | 基础力道 +1，本局限 3 次 `[v1假设]` |
| 奇遇 | 附加词缀（如“首手伤害 +15%”） |
| 渡劫奖励 | 稀有武器词缀/灵化 |
| 符箓“炼器符” | 立即强化一次（不占坊市次数） |

> 武器成长只增加“基础”，不直接放大卦倍率；乘区仍由法宝与卦象提供，避免数值失控。

---

## 7. 边界与异常

| 情况 | 处理 |
|------|------|
| 附魔槽满 | 新附魔顶替最旧；UI 在写入前提示将被顶替的附魔 |
| 同名附魔 | 按效果定义刷新/叠层；未定义时默认刷新持续时间 |
| 附魔冲突 | 后写入的覆盖先写入；不允许多个互斥附魔同时存在 |
| 武器被禁用（Boss 规则） | 攻击仍可进行，但基础力道视为 0 或攻击模式失效（按 Boss 规则） |
| 攻击段数为 0 | 视为不能攻击；给出提示 |

## 9. 待验证问题

1. 本局不可更换武器是否会让构筑过于单一？是否需要“副武器”槽？
2. 附魔先入先出是否有趣？还是应该允许玩家手动选择顶替哪个附魔？
3. 五行亲和 +25% 是否足以引导玩家选择对应道途/卦象？
4. 炼器 +1 基础力道 ×3 是否太弱/太强？
5. 群攻与连击的叠加是否会放大数值失控风险？
