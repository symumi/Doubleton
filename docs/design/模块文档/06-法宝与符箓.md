# 06 · 法宝与符箓

> 版本：v0.2 ｜ 依赖：03 战斗、04 卦象、08 坊市 ｜ 总纲：`../核心玩法策划.md` §4.3 / §4.4

## 1. 模块目标

定义两类构筑资源：

- **法宝**：被动构筑位，类似小丑牌 Joker，负责乘区、触发与特殊规则；
- **符箓**：一次性消耗品，类似塔罗/星球牌，负责操作、资源、防御与转化。

---

## 2. 法宝（被动构筑位）

### 基础规则

| 项目 | v1 默认值 |
|------|-----------|
| 槽位 | 4–5 个 `[v1假设]` |
| 品阶 | 凡品 → 灵品 → 玄品 → 地品 → 天品 |
| 获取 | 坊市购买、渡劫奖励、奇遇、开局初始 |
| 触发时机 | 战斗开始、回合开始、出卦、命中、击杀、战斗结束等 |
| 叠加 | 同名法宝不叠加，重复时转换为灵石/升级 |

### 品阶与强度

| 品阶 | 定位 | 稀有度 |
|------|------|--------|
| 凡品 | 小加成、资源型 | 常见 |
| 灵品 | 条件加伤 | 常见 |
| 玄品 | 明确流派核心 | 少见 |
| 地品 | 强乘区/规则改变 | 稀有 |
| 天品 | 构筑质变 | 极稀有 |

### 法宝示例

| 法宝 | 品阶 | 效果 |
|------|------|------|
| 火德星君令 | 灵品 | 打出火属性卦象时，本手卦力 ×1.5 |
| 泰卦真解 | 玄品 | 合成“泰卦”时：抽 1 张并回复 1 灵力 |
| 连山印 | 地品 | 每回合第一手伤害 ×2 |
| 噬嗑牙 | 地品 | “噬嗑”卦的连击每段附加 1 层灼烧 |
| 阴阳鱼 | 天品 | 每打出 3 个阴卦，下个阳卦伤害 ×3 |
| 赑屃镇 | 凡品 | 每场战斗第一次濒死时保留 1 HP（每局一次） |

## 3. 符箓（一次性消耗品）

### 基础规则

| 项目 | v1 默认值 |
|------|-----------|
| 携带上限 | 5 张 `[v1假设]` |
| 使用时机 | 玩家回合内；部分符箓可在战斗前使用（见下表） |
| 消耗 | 使用后从本局移除 |
| 获取 | 坊市、战斗奖励、奇遇、渡劫奖励 |

### 符箓类型

| 类型 | 作用 | 示例 |
|------|------|------|
| 操作型 | 改变出牌/顺序 | 逆转符：交换本手内/外卦顺序 |
| 检索型 | 找牌/看牌 | 观星符：查看牌堆顶 5 张，将其中 1 张加入手牌 |
| 资源型 | 回灵/加钱 | 补天丹：本回合灵力 +1；招财符：立即获得灵石 |
| 防御型 | 免伤/解状态 | 避水诀：本回合免疫水/寒类减益 |
| 转化型 | 改变牌/卦 | 变卦符：本手将一张牌视为指定八卦 |
| 强化型 | 升级/强化 | 炼器符：立即强化武器一次 |

> 符箓的“使用时机”必须在数据中明确；战斗外可用的符箓需要在路线页/坊市页提供入口。

## 4. 获取与使用流程

```
获得法宝/符箓
   │
   ├─ 法宝：进入法宝栏（槽满时提示替换/放弃）
   └─ 符箓：进入符箓栏（上限 5，满时提示替换/放弃）
        │
        ▼
战斗中玩家回合
   │
   ├─ 点击符箓 → 查看效果/目标 → 确认使用 → 结算 → 消耗
   └─ 法宝：满足触发条件时自动结算
```

- 法宝不可主动“使用”，只在触发时机自动生效。
- 符箓必须手动使用；使用后不可撤销。
- 战斗外可用的符箓在路线页/坊市页显示入口。

---

## 5. 联动规则

| 联动对象 | 规则 |
|----------|------|
| 卦象 | 法宝按卦名/五行/阴阳/是否会心等标签触发 |
| 武器 | 法宝可修改基础力道、攻击段数、附魔槽规则 |
| 符箓 | 符箓可改变出牌顺序、视为卦、回灵、检索；不能直接触发“法宝购买” |
| 敌人 | Boss 规则可禁用某个法宝槽（下回合恢复） |
| 经济 | 重复法宝可转换为灵石；出售法宝返还部分灵石 `[待验证]` |

---

## 6. 边界与异常

| 情况 | 处理 |
|------|------|
| 法宝槽满 | 购买/获得前必须选择替换或放弃；不可超槽 |
| 重复法宝 | 默认转换为灵石；特殊法宝可叠加/升级（按数据定义） |
| 符箓栏满 | 同上；不可超上限 |
| 战斗中无法使用 | UI 灰置并提示原因（时机不对/目标不合法） |
| 法宝被禁用 | 显示禁用图标；不触发，不占位？`[待验证]` |
| 符箓效果目标不存在 | 不消耗符箓，给出提示 |

---

## 7. 数值与稀有度 `[v1假设]`

| 项目 | 默认 |
|------|------|
| 法宝槽 | 4–5 |
| 符箓携带 | 5 |
| 凡/灵/玄/地/天权重 | 40% / 30% / 18% / 10% / 2% |
| 重复法宝转换 | 凡 5 / 灵 10 / 玄 20 / 地 35 / 天 60 灵石 |
| 坊市刷新 | 20 灵石/次，每境界 1–2 次 |

## 9. 待验证问题

1. 法宝槽 4 个还是 5 个？哪个更容易形成“有取舍的构筑”？
2. 重复法宝转灵石是否会稀释“抽到好东西”的爽感？
3. 符箓上限 5 是否够用？是否需要“符箓袋”扩展？
4. Boss 禁用法宝是否过于惩罚？应该禁用 1 个还是随机禁用？
5. 法宝触发顺序固定从左到右是否可接受？是否需要“结算顺序”UI？
