# 07 · 敌人与渡劫 Boss

> 版本：v0.2 ｜ 依赖：03 战斗、09 境界 ｜ 总纲：`../核心玩法策划.md` §5.1 / §5.5

## 1. 模块目标

定义战斗中的敌方单位：属性、意图、行为模式，以及每境界第三关的**渡劫 Boss**与规则改造。

---

## 2. 敌人属性

| 属性 | 说明 |
|------|------|
| 类型 | 小怪 / 精英 / 渡劫 Boss |
| 气血 HP | 击败条件 |
| 力道 | 攻击基础值 |
| 五行 | 金/木/水/火/土；参与克制 |
| 抗性 | 五行减伤/免疫（可选） |
| 护甲 | 固定减伤，先于护盾/HP |
| 意图 | 下回合行动预览 |
| 状态 | 灼烧/寒滞/易伤/虚弱等 |
| 规则 | Boss 的规则改造，仅渡劫 Boss 拥有 |

---

## 3. 敌人类型

| 类型 | 出现位置 | 行为 | 奖励 |
|------|----------|------|------|
| 小怪 | 守关一 / 守关二 | 单五行，攻击/防御二选一 | 灵石 25–35 |
| 精英 | 守关二 | 双行为轮换 + 1 个专属技能 | 灵石 35–50 + 概率符箓 |
| 渡劫 Boss | 每境界第三关 | 高 HP + 规则改造 | 灵石 60–80 + 法宝/稀有符箓 |

> 渡劫 Boss 是每境界的主题难题；胜利后晋升下一境界，失败则本局结束。

---

## 4. 意图系统

- 敌人下回合的行动**提前可见**，显示在敌人面板上。
- 玩家据此决定本手摆什么卦、是否留牌/用符箓。
- 意图类型：

| 意图 | 说明 | 玩家应对 |
|------|------|----------|
| 攻击 | 造成固定/浮动伤害 | 护盾、减伤、抢先击杀 |
| 上状态 | 施加灼烧/虚弱/易伤等 | 解除/免疫/速杀 |
| 改变环境 | 改变卦象判定/五行/手牌 | 调整出卦顺序 |
| 召唤 | 召唤小怪 | 群攻/优先击杀 |
| 蓄力 | 本回合不攻击，下回合大招 | 打断/爆发/防御 |

- `[v1假设]` 意图不可被隐藏；天劫难度可通过“隐藏意图”词条增加压力。

---

## 5. 敌人行为模式

### 小怪

- 固定循环：攻击 → 防御 → 攻击……；
- 或条件触发：血量低于 50% 时改为防御/狂暴。

### 精英

- 双行为轮换：技能 A → 技能 B → 技能 A……；
- 带 1 个专属技能（如“藤缚”“石甲”“火雨”）。

### 渡劫 Boss

- 高 HP + 规则改造；
- 部分技能免疫控制（寒滞层数上限/免疫）；
- 规则改造在战斗开始前显示，玩家可提前调整构筑。

---

## 6. 渡劫 Boss 规则改造（示例池）

| 渡劫 Boss | 规则改造 |
|-----------|----------|
| 玄冥水君 | 每回合敌人先行动；你打出的卦象五行视为水 |
| 乱序道人 | 你出牌时内/外卦判定随机颠倒（预览仍显示实际卦名） |
| 离火妖王 | 免疫火属性；每次你打出火卦，本回合灵力 -1 |
| 艮山巨灵 | 护甲极高，只有“破甲/贯穿（巽系）”卦能高效输出 |
| 噬法魔 | 你每回合第一个法宝被禁用（下回合恢复） |
| 镜妖 | 复制你上一个卦象的持续效果施加给你自己 |

> 渡劫胜利后的结算统一提示“渡劫成功 · 晋升××”；失败则本局构筑结束，保留图鉴与少量道行。

---

## 7. 五行与克制

- 攻击五行 = 内卦五行（见 04）。
- 克制关系：金克木、木克土、土克水、水克火、火克金。
- 系数：克制 ×1.5 ｜ 被克 ×0.67 ｜ 同属 ×1.0（敌人同属性 ×0.85）`[v1假设]`。
- 敌人可带五行抗性：对某五行伤害减半/免疫，用于制造“因敌配卦”的压力。

---

## 8. 强度曲线 `[v1假设]`

| 境界 | 小怪 HP | 精英 HP | 渡劫 Boss HP | 敌人伤害 |
|------|---------|---------|--------------|----------|
| 炼气期 | 20–30 | 35–45 | 55–70 | 4–8 |
| 筑基期 | 35–50 | 60–80 | 95–120 | 7–12 |
| 金丹期 | 55–75 | 90–120 | 150–200 | 10–18 |

- 敌人强度随境界递增；天劫难度在基础上追加倍率。
- 精英约为普通小怪的 1.5× HP；渡劫 Boss 约为 2.5× HP `[v1假设]`。
- 具体数值以战斗原型测试为准，不在文档中硬编码。

---

## 9. 边界与异常

| 情况 | 处理 |
|------|------|
| 敌人免疫控制 | 寒滞/眩晕不生效，显示“免疫” |
| 状态层数上限 | 灼烧/易伤等设上限，防止无限叠层 |
| 敌人在己方回合死亡 | 立即进入胜利判定；后续效果不再结算 |
| 召唤物 | 计入敌方单位；全灭才胜利（除非规则另有说明） |
| Boss 规则与法宝冲突 | Boss 规则优先；冲突时 UI 提示 |
| 敌人意图被改变 | 意图刷新时给出动画/提示，避免玩家误判 |

## 11. 待验证问题

1. 敌人意图是否应始终可见？隐藏意图会不会让战斗变成纯猜？
2. 渡劫 Boss 的规则改造哪些“有趣但公平”、哪些过于惩罚？
3. 五行抗性应该做“减伤”还是“免疫”？免疫是否会让某条构筑路线直接废掉？
4. 精英的专属技能是否应提前显示冷却/循环？
5. 敌人强度曲线与玩家构筑成长曲线是否匹配？
