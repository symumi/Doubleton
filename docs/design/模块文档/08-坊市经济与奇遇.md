# 08 · 坊市经济与奇遇

> 版本：v0.2 ｜ 依赖：02 单局流程、06 法宝符箓、09 境界 ｜ 总纲：`../核心玩法策划.md` §6

## 1. 模块目标

定义局内经济循环：灵石的收入与消耗、坊市商品与刷新、服务（炼器/删牌/升级）、奇遇事件，以及它们在单局中的出现时机。

---

## 2. 灵石（局内货币）

| 项目 | 内容 |
|------|------|
| 名称 | 灵石 |
| 来源 | 战斗胜利、资源卦（如火天大有）、符箓（招财符）、奇遇 |
| 消耗 | 购买法宝/符箓、刷新货架、炼器、删牌、升级牌 |
| 保留 | 局内保留，一局结束后不带走 |

---

## 3. 坊市结构

### 商品位

| 商品位 | 数量 | 内容 |
|--------|------|------|
| 法宝位 | 2 | 从法宝池随机，受境界/天劫影响 |
| 符箓位 | 1–2 | 从符箓池随机 |
| 服务位 | 1 | 炼器 / 删牌 / 升级牌 / 洗牌（随机或固定） |

> `[v1假设]` 每次刷新 3–5 个商品位；MVP 采用 2 法宝 + 1 符箓 + 1 服务 + 1 随机位。

### 刷新

| 项目 | 默认 |
|------|------|
| 刷新费用 | 20 灵石/次 `[v1假设]` |
| 刷新次数 | 每境界 1–2 次 |
| 刷新内容 | 重新随机商品位；已购买/售罄的位置保留空位 |
| 价格浮动 | 天劫难度可提高商品价格 |

---

## 4. 商品类型

### 法宝

- 从已解锁法宝池随机；
- 品阶权重：凡 40% / 灵 30% / 玄 18% / 地 10% / 天 2% `[v1假设]`；
- 购买后进入法宝栏；槽满时提示替换/放弃。

### 符箓

- 从符箓池随机；
- 购买后进入符箓栏；上限 5 张；
- 部分符箓可在战斗外使用（见 06）。

### 服务

| 服务 | 效果 | 价格 | 限制 |
|------|------|------|------|
| 炼器 | 武器基础力道 +1 | 30 `[v1假设]` | 本局限 3 次 |
| 删牌 | 从牌组移除 1 张八卦牌 | 25 起，每次 +10 | 可重复 |
| 升级牌 | 选 1 张八卦牌品级 +1 | 40 `[v1假设]` | 受品级上限限制 |
| 洗牌 | 重排抽牌堆顺序 | 15 `[v1假设]` | 每局限 1 次 |

> 服务价格与次数为 v1 假设，需通过经济测试调整。

## 5. 奇遇

### 触发

- 一局固定 **1 次奇遇** `[v1假设]`，位于筑基后期（第 5 关）胜利后；
- 后续可扩展为随机节点池。

### 事件结构

```
奇遇标题 + 描述
   │
   ├─ 选项 A（风险/收益）
   ├─ 选项 B（保守/资源）
   └─ 选项 C（离开/放弃）
        │
        ▼
结算结果 → 回到路线页
```

### 事件类型

| 类型 | 示例 | 结果 |
|------|------|------|
| 资源 | 遇到散修遗府 | 获得灵石/符箓 |
| 风险 | 强行吸收灵气 | 获得稀有牌，但失去气血/护盾 |
| 抉择 | 两件法宝二选一 | 选择其一，另一件消失 |
| 图鉴 | 参悟古碑 | 解锁一个未发现的卦象图鉴 |
| 转化 | 卦象置换 | 将一张牌转为指定卦 |

## 6. 出现时机

| 节点 | 类型 | 触发 |
|------|------|------|
| 筑基渡劫胜利后 | 坊市 ① | 补充构筑，准备筑基期 |
| 筑基后期胜利后 | 奇遇 ① | 一次抉择 |
| 金丹渡劫胜利后 | 坊市 ② | 最终调整，准备元婴渡劫 |

> 坊市/奇遇不消耗关卡次数，结束后回到路线页。

## 8. 边界与异常

| 情况 | 处理 |
|------|------|
| 灵石不足 | 购买按钮灰置；提示差额 |
| 商品售罄 | 显示“已售出”遮罩，不可重复购买 |
| 刷新次数用尽 | 刷新按钮灰置 |
| 法宝/符箓栏满 | 购买前弹出替换/放弃选择 |
| 离开坊市 | 已购买内容保留；未购买商品消失 |
| 退款 | 不支持退款；购买前二次确认 |
| 战斗中使用坊市 | 不允许；坊市只在路线页进入 |

## 10. 待验证问题

1. 20 灵石刷新是否太贵/太便宜？是否应该随刷新次数递增？
2. 删牌价格每次 +10 是否能有效阻止“删空牌组”？
3. 奇遇固定 1 次是否太可预测？是否需要 2–3 个随机事件池？
4. 服务位随机还是固定？随机是否会带来“没得选”的挫败？
5. 渡劫前的坊市是否应该打折/必出关键商品？
