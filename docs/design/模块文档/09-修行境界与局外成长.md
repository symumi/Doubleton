# 09 · 修行境界与局外成长

> 版本：v0.2 ｜ 依赖：01 总流程、02 单局流程、07 渡劫 Boss ｜ 总纲：`../核心玩法策划.md` §2.4 / §6.3

## 1. 模块目标

定义“修仙进度”如何与关卡挂钩：境界推进、渡劫晋升、局外道行结算、永久解锁与天劫难度。

---

## 2. 境界结构

一局采用 **3 境界 × 3 关**，每境界第三关为渡劫：

| 境界 | 守关一 | 守关二 | 渡劫（Boss） | 渡劫结果 |
|------|--------|--------|--------------|----------|
| 炼气期 | 炼气一层（普通） | 炼气圆满（精英） | 筑基渡劫 | 晋升筑基 |
| 筑基期 | 筑基初期（普通） | 筑基后期（精英） | 金丹渡劫 | 晋升金丹 |
| 金丹期 | 金丹初期（普通） | 金丹后期（精英） | 元婴渡劫 | 晋升元婴 |

> 本局通关时晋升元婴；元婴期及更高境界（化神 → 炼虚 → 合体 → 大乘 → 渡劫飞升）作为长线扩展 / 高天劫内容。

---

## 3. 渡劫流程

```
路线页进入渡劫关
   │
   ▼
渡劫 Boss 战（附带规则改造）
   │
   ├─ 胜利 → 渡劫成功 · 晋升×× → 境界奖励 → 下一境界
   └─ 失败 → 本局结束 → 失败结算（保留图鉴与少量道行）
```

- 渡劫是每境界的“考试”，不是可选内容。
- 渡劫 Boss 的规则改造在战斗前可见，玩家可在上一节点坊市调整构筑。
- 渡劫胜利的结算文本统一为“渡劫成功 · 晋升××”。

## 4. 境界奖励 `[v1假设]`

| 晋升 | 奖励 |
|------|------|
| 筑基 | 灵石 30 + 随机符箓 1 张 |
| 金丹 | 灵石 50 + 随机法宝 1 件 |
| 元婴 | 通关结算，进入道行结算 |

> 境界奖励与渡劫战斗掉落分开；具体数值待经济测试。

## 5. 局外货币：道行

| 项目 | 内容 |
|------|------|
| 名称 | 道行 |
| 来源 | 通关结算、失败结算（少量）、首次击败渡劫 Boss |
| 用途 | 永久解锁武器/法宝/符箓/道途/图鉴条目/天劫难度 |
| 是否影响局内数值 | 否；局外只解锁选项，不做永久数值变强 |

---

## 6. 局外解锁

| 解锁类型 | 示例 |
|----------|------|
| 武器/功法 | 新攻击模式、新五行亲和 |
| 法宝 | 新法宝进入坊市池 |
| 符箓 | 新符箓进入掉落/商店池 |
| 道途 | 新开局倾向（火行/水行/金行等） |
| 图鉴 | 已发现卦象详情、熟练度奖励 |
| 天劫 | 更高难度词条 |

---

## 7. 天劫难度（与渡劫区分）

> **渡劫** = 局内 Boss 战；**天劫** = 局外难度词条。两者不是同一概念。

| 天劫等级 | 示例词条 |
|----------|----------|
| 天劫 0 | 基础难度，无额外词条 |
| 天劫 1 | 敌人 HP +20% |
| 天劫 2 | 商店价格 +20% |
| 天劫 3 | 每场战斗禁用一种八卦 |
| 天劫 4 | 敌人意图隐藏 |
| 天劫 5 | 渡劫 Boss 额外规则改造 |
| 天劫 6+ | 组合词条、牌堆诅咒、初始资源减少 |

- 天劫逐级解锁；玩家可自选已解锁的最高天劫。
- 天劫只增加压力，不改变核心规则。

## 8. 存档与重置

| 数据 | 生命周期 |
|------|----------|
| 局内境界/牌组/法宝/符箓/灵石 | 本局结束清空 |
| 图鉴发现/熟练度 | 永久保留 |
| 道行/解锁 | 永久保留 |
| 天劫最高等级 | 永久保留 |
| 战斗中断线 | 恢复到本场战斗开始 |

## 11. 待验证问题

1. 一局 3 境界是否足够？是否需要第 4 境界（元婴）作为完整通关？
2. 渡劫失败是否应保留本局已获得的一部分奖励？
3. 道行结算是否足够驱动重复游玩？解锁节奏是否太慢？
4. 天劫词条是否应允许玩家自选/禁用某些词条？
5. 长线境界（化神→大乘）是接在同一局里，还是作为二周目/无尽模式？
