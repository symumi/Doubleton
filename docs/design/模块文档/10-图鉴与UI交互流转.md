# 10 · 图鉴与 UI 交互流转

> 版本：v0.2.1 ｜ 依赖：01 总流程、04 卦象、08 坊市、09 境界、13 存档 ｜ 视觉规范：`../视觉设计风格.md`

## 1. 模块目标

定义玩家在局内/局外看到的主要页面、页面之间的流转关系，以及核心交互（出卦、购买、图鉴查看）的反馈规范。

本模块描述“信息架构与交互”，不重复视觉规范；配色、材质、字体、动效细节以 `../视觉设计风格.md` 为准。

## 4. 卦象图鉴

### 布局

- **8×8 网格**：行 = 上卦，列 = 下卦；共 64 格。
- 每格显示：六爻卦画、卦名（未发现为 `？？？`）、熟练度圆点、精通标记。
- 顶部：已发现数量、精通数量、筛选（全部/已发现/未发现/按五行/按上卦）。
- 右侧详情面板：卦名、编号、上卦/下卦、卦德、效果、五行结算、伤害示例、顺序换位提示、联动法宝、熟练度、图鉴完成度。

### 状态

| 状态 | 表现 |
|------|------|
| 已发现 | 正常卦画 + 卦名 + 熟练度 |
| 未发现 | 暗色爻画 + `？？？` |
| 新发现 | `NEW` 标记 |
| 精通 | 卦名高亮 + 精通标记 |

### 完成度奖励 `[v1假设]`

| 完成度 | 奖励 |
|--------|------|
| 25% | 道行 +20 |
| 50% | 解锁一个符箓配方 |
| 75% | 解锁一个法宝 |
| 100% | 解锁隐藏道途/皮肤 |

## 5. 战斗 UI 布局

```
┌──────────────────────────────────────────────┐
│ 顶部：玩家状态 / 敌人 / 意图 / 本局路线      │
├──────────────────────────────────────────────┤
│ 中部：卦台（外卦 + 内卦 = 卦象预览）         │
│      效果预览 / 伤害预估 / 五行提示           │
├──────────────────────────────────────────────┤
│ 底部：手牌（6 张）｜符箓｜法宝｜出卦/弃牌按钮  │
└──────────────────────────────────────────────┘
```

- 顶部必须始终可见：敌人 HP、五行、意图、玩家 HP/护盾/灵力。
- 中部卦台是核心信息区：选择手牌时实时预览“将合成什么卦、效果、预估伤害”。
- 底部手牌支持点击/拖拽；选中内卦/外卦有明确标签。
- 法宝/符箓区固定在边缘，不遮挡手牌与卦台。

## 6. 核心交互

### 出卦

1. 点击第一张手牌 → 标记为“内卦（下）”。
2. 点击第二张手牌 → 标记为“外卦（上）”。
3. 卦台实时显示卦名、效果、伤害预估、五行克制。
4. 点击“出卦” → 结算动画 → 伤害数字 → 手牌消耗。
5. 出卦前可点击已选手牌取消；出卦后不可撤销。

### 弃牌 / 符箓

- 弃牌：进入弃牌模式 → 选择 N 张 → 确认 → 抽 N 张。
- 符箓：点击符箓 → 查看效果/目标 → 确认 → 消耗。
- 两者都必须在玩家回合内，且不处于结算动画中。

### 确认与取消

| 操作 | 是否需要确认 |
|------|--------------|
| 出卦 | 否（但提供预览） |
| 弃牌 | 是（显示弃牌数量） |
| 使用符箓 | 是（部分高价值符箓） |
| 离开坊市 | 是（提示未购买商品将消失） |
| 放弃本局 | 是（二次确认） |

## 7. 反馈规范

| 反馈 | 内容 |
|------|------|
| 伤害数字 | 大而清晰；会心/克制/法宝加成用不同颜色 |
| 卦象动画 | 内外卦合成、卦名浮现、六爻亮起 |
| 状态图标 | 灼烧/寒滞/易伤/虚弱/护盾/破甲 |
| 错误提示 | “灵力不足”“手牌不足 2 张”“该符箓此时不可用” |
| 关键决策 | 出卦前显示预估伤害与斩杀提示 |

> 动效细节以 `../视觉设计风格.md` §7 为准；本模块只定义“必须反馈什么”。

## 8. 边界与异常

| 情况 | 处理 |
|------|------|
| 误点出卦 | 出卦前可取消；出卦后不可撤销 |
| 图鉴未解锁 | 显示 `？？？` 与暗色爻画，不显示效果 |
| 弹窗遮挡 | 弹窗出现时暂停底层交互 |
| 小分辨率/窗口 | 以 1920×1080 为基准；低于基准时优先保证卦台与手牌 |
| 手柄/键盘 | 所有核心操作必须可映射到手柄/键盘 |
| 战斗动画中点击 | 忽略输入，避免重复结算 |

## 10. 待验证问题

1. 出卦用“点击两张牌”还是“拖拽到卦台”？哪种更快、更少误操作？
2. 图鉴未发现时是否应该显示卦画轮廓？会不会泄露太多？
3. 伤害预估是否应该显示“斩杀线”？会不会降低决策乐趣？
4. 手柄操作在 8×8 图鉴上是否需要网格导航优化？
5. 战斗中查看图鉴是否需要暂停敌人计时（当前为回合制，可随时查看）？
