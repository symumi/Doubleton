## 2. MVP 内容清单

| 类别 | MVP 范围 |
|------|----------|
| 八卦牌 | 8 种卦 × 品级 1–3 星 |
| 卦象 | 64 卦全部可合成；其中 16 个精修独特卦辞，其余走模板 |
| 武器/功法 | 3 种（直伤 / 连击 / 群攻各一） |
| 法宝 | 约 20 个 |
| 符箓 | 约 8 个 |
| 敌人 | 小怪 6、精英 3、渡劫 Boss 3（筑基 / 金丹 / 元婴渡劫） |
| 单局结构 | 3 境界（炼气 / 筑基 / 金丹）约 9 场战斗（含 3 次渡劫）+ 2 次坊市 + 1 次奇遇 |
| 图鉴 | 卦象网格 + 效果预览 + 熟练度 |
| 局外 | 基础解锁 3 档（武器/法宝/道途） |
| 难度 | 天劫 0–1（先验证基础难度与一个 modifier） |
| 存档 | 1 个自动存档槽：局外永久数据、局内节点进度、玩家回合开始战斗快照；主界面“继续游戏” |

## 3. 开发优先级

### P0：核心循环（必须先做）

1. 战斗回合流程（玩家回合 → 敌方回合 → 胜负判定）。
2. 出卦：内卦/外卦 → 64 卦合成 → 伤害公式 → 状态/附魔。
3. 8 种八卦牌 + 牌堆/手牌/弃牌。
4. 1 种武器 + 1 个境界 + 1 个渡劫 Boss。
5. 基础 UI：战斗界面、伤害预览、胜负结算。

### P1：单局闭环

1. 3 境界 × 3 关的路线页与顺序推进。
2. 坊市（商品/刷新/炼器/删牌）。
3. 法宝/符箓的基础获取与使用。
4. 渡劫晋升与一局结算。
5. 图鉴 8×8 网格与详情。
6. 存档与继续游戏：局外永久保存、局内节点恢复、战斗快照恢复到玩家回合开始。

### P2：内容与打磨

1. 补齐 64 卦特殊效果与文案。
2. 法宝池扩到 20、符箓 8。
3. 敌人意图表现、伤害数字、卦象动画。
4. 天劫 0–1、局外解锁 3 档。
5. 平衡与 playtest 迭代。

## 4. 里程碑

| 里程碑 | 目标 | 验收 |
|--------|------|------|
| M1 战斗原型 | 1 个境界、1 个 Boss、8 卦可出 | 能完整打完一场战斗，出卦/伤害/胜负正确 |
| M2 单局闭环 | 3 境界 9 战、坊市、渡劫 | 能从开局打到通关/失败，无阻断性 bug |
| M3 内容补齐 | 64 卦、20 法宝、8 符箓、6+3+3 敌人 | 内容量达到 MVP 清单 |
| M4 平衡与打磨 | 数值、UI、动效、天劫 0–1 | 通过验收标准，进入外部 playtest |

---

## 5. MVP 验收标准

- **理解成本**：不教学也能在 2 局内理解「内/外卦、五行克制、法宝乘区」。
- **构筑成型**：第 3 境界的「元婴渡劫」前，能稳定形成一套成型构筑。
- **节奏**：单局 30–40 分钟，无严重卡顿或卡手死局。
- **数值**：后期有爆发感，但不出现万亿级失控；渡劫有压力但可通关。
- **流程**：从主界面 → 开局 → 9 战 → 通关/失败 → 局外结算，全流程无阻断。
- **内容**：64 卦全部可合成；至少 16 个特殊卦有独立效果；图鉴可查看。
- **存档**：退出后可从主界面继续；战斗内继续回到玩家回合开始，手牌/牌堆/敌人意图/资源不重掷。

## 6. 风险与对策

| 风险 | 对策 |
|------|------|
| 玩家对 64 卦 + 五行陌生 | 图鉴网格、出牌预览、新手局只开放部分卦、白话效果 |
| 只有 8 种牌导致组合单调 | 品级/词缀/特殊牌；变爻与天干扩展位 |
| 内/外顺序反直觉 | UI 强引导、实时预览、结算动画强调上下结构 |
| 附魔/状态数值爆炸 | 附魔槽 FIFO + 灵力上限 + 法宝乘区刹车 |
| 64 卦内容成本高 | 模板矩阵 + 8–16 个特殊卦 |
| 渡劫 Boss 规则过于惩罚 | 规则提前显示、渡劫前坊市、限制规则数量 |
| 单局 9 战过长 | 可配置普通关数量；测试 30–40 分钟目标 |

## 7. 待验证问题

1. 两张牌成卦是否决策太轻？是否需要三张成卦或变爻扩展？
2. 每回合 2–3 手是否足够爽？灵力模型是否卡手？
3. 五行克制 ±50% 是否过于主导？
4. 附魔先入先出是否有趣？是否允许手动选择顶替？
5. 64 卦中是否存在“废卦”或“唯一最优卦”？
6. 局外只解锁不变强，是否足够驱动重复游玩？
7. 渡劫 Boss 规则改造哪些有趣但公平？
