# 《卦锻》视觉设计风格规范

> 版本：v0.1（原型评审稿）｜状态：待评审｜适用范围：战斗、坊市、图鉴、修行路线及后续同世界观界面
> 依据：`docs/design/核心玩法策划.md` v0.2 ｜原型目录：`docs/prototype/`
> 风格代号：**墨狱异志录**

---

## 1. 风格命题

### 1.1 一句话方向

玩家不是在操作一套干净的修仙 UI，而是在翻阅一本被妖异侵蚀的《异志录》。玩家亲手写下的卦、阵、符与行动必须清晰可控；外部世界、敌人与未知系统则不断从册页边缘渗入墨污、红印与失真信号。

### 1.2 关键词配比

| 关键词 | 配比 | 视觉职责 |
|---|---:|---|
| 水墨 | 30% | 宣纸底、墨晕、枯笔、留白、黑白灰层次 |
| 怪奇 | 20% | 不对称轮廓、异形纹样、缺失信息、似眼非眼的空洞 |
| 卦象 | 15% | 六爻线、八卦符号、8×8 矩阵、内外卦上下关系 |
| 约束感（玩家可控） | 15% | 固定网格、明确选中、资源数值、行动边界、可撤回感 |
| 杂乱感（场景/外部系统） | 10% | 墨渍、错位标签、外部噪声、未对齐的小物件 |
| 轻微赛博 | 5% | 灵青色扫描线、等宽数字、极少量信号错位 |
| 微恐 | 5% | 朱砂、暗红注视点、被遮住的信息、异常重复 |

> “异志录”不是额外堆叠的古风元素，而是整体叙事框架：每个界面都是一页被观察、被记录、被污染的志怪册页。

## 2. 视觉双层模型

### 2.1 约束层：玩家可控

约束层代表玩家“落笔成卦”的秩序，必须始终清晰、稳定、可预测。

- 使用固定网格和规整间距。
- 选中、确认、消耗、可行动状态使用明确边界和灵青色高亮。
- 数值、资源、伤害预览、敌人意图必须保持最高可读性。
- 动效短促、可逆、无遮挡；不使用长时间遮屏特效。
- 交互按钮使用“符令/木牌/硬质卡片”质感，不漂浮、不软化。

### 2.2 杂乱层：场景与外部系统

杂乱层代表世界、妖物、未知、锁区与外部规则，允许更自由、更脏、更不对称。

- 墨渍、裂纹、纸纤维、边缘侵蚀可以溢出网格，但不能盖住关键数字。
- 未解锁、未知、Boss、被规则改造的状态使用朱砂、暗红和低对比阴影。
- 坊市商品、敌人、地图节点允许轻微错位和不同大小的标签。
- 轻微赛博只出现在扫描线、信号错位、等宽数字和局部青光，不做霓虹未来城市。

### 2.3 分层边界

| 层级 | 可以脏 | 必须清晰 | 禁止 |
|---|---|---|---|
| 玩家操作 | 否 | 手牌、灵力、按钮、伤害预览、选中状态 | 被墨渍遮挡、动画延迟操作 |
| 敌人/场景 | 是 | HP、意图、五行、危险提示 | 恐怖效果盖住伤害或规则 |
| 图鉴/未知 | 部分 | 已发现卦名、五行、熟练度 | 未发现信息被误读为已解锁 |
| 坊市/外部系统 | 部分 | 价格、库存、购买结果 | 商品视觉压过价格与按钮 |

## 3. 色彩系统

### 3.1 主色

| 色名 | 色值 | 用途 |
|---|---|---|
| 墨骨黑 | `#070808` | 页面底色、最深阴影、墨池 |
| 夜宣 | `#111210` | 面板底、册页背面 |
| 灰纸 | `#C8BFA8` | 正文、纸纤维、未强调文字 |
| 符金 | `#C2AA72` | 卦纹、边界、品阶、古老文字 |
| 朱砂 | `#B63A31` | 渡劫、危险、未解锁、封印、红印 |
| 灵青 | `#5EC8C0` | 玩家选中、可控资源、扫描线、当前行动 |

### 3.2 功能色

| 功能 | 色彩策略 |
|---|---|
| 玩家当前选择 | 灵青实线 + 局部青光 |
| 玩家确认/出牌 | 符金渐变 + 暗色文字 |
| 敌人危险 | 朱砂红，禁止大面积纯红 |
| 可斩杀/正向反馈 | 低饱和青绿，不使用明艳荧光绿 |
| 未知/锁定 | 灰褐降低对比，加斜向侵蚀纹理 |
| 五行 | 金=灰白、木=灰绿、水=冷青、火=朱橙、土=灰黄，保持低饱和 |

### 3.3 比例

- 墨色/黑色底：60%
- 灰纸与正文：20%
- 符金：10%
- 朱砂：5%
- 灵青与其他功能色：5%

朱砂与灵青都属于“高信息色”，一次界面中只用于状态变化，不作为大面积装饰。

## 4. 字体与数字

| 内容 | 字体建议 | 规则 |
|---|---|---|
| 大标题、卦名、境界名 | 楷体 / 宋体类 | 有笔锋，字距略宽，不做书法长卷排版 |
| 正文、按钮、说明 | 微软雅黑 / 思源黑体 | 保证小字号可读性 |
| 数值、伤害、资源 | 等宽字体 | 数字必须一眼可比较，允许轻微灵青残影 |
| 未解锁文本 | 黑体或楷体 | 降低对比，不使用模糊到不可读的滤镜 |

标题可以“古”，正文和数值必须“准”。不要让整套 UI 都使用书法字体。

## 5. 材质与图形语言

### 5.1 水墨

- 底纹使用宣纸纤维、墨晕、枯笔和留白，不直接贴一整张写实水墨画。
- 墨渍主要集中在面板边缘、场景空白区和外部系统周围。
- 玩家操作区内部尽量干净，墨只在外框或角落出现。

### 5.2 卦象

- 六爻线是核心识别符号，保持横平竖直、粗细一致。
- 内外卦必须明确上下关系，预览区优先展示“上卦/下卦”而不是只展示卦名。
- 8×8 图鉴用矩阵表达“还缺哪个组合”，不改成列表。
- 卦象纹样可以进入边框、按钮角标、进度条，但不能替代功能文字。

### 5.3 异志录

- 每个主面板可视为一页册页，允许轻微纸纤维、印章、编号和批注。
- 面板右下可使用低对比“志”字水印，不能影响正文。
- 信息标签采用批注、签条、封签的形式，不使用现代卡片阴影。

### 5.4 轻微赛博

- 仅使用灵青扫描线、1px 信号错位、等宽数字和少量横向切片。
- 赛博元素只出现在“系统被扰动”或“玩家正在读取”的局部。
- 禁止霓虹边框、发光网格、全息投影和未来城市 UI。

### 5.5 微恐

- 用“看不清”“记录缺失”“重复出现的符号”制造不安，不依赖血腥。
- 敌人区域可使用暗红注视点、似眼空洞、错位横线。
- 未解锁格可加斜向侵蚀和局部模糊，但不能让玩家无法判断锁定状态。

## 6. 组件规则

### 6.1 面板

- 外框为硬边册页，圆角不超过 11px，右上可略圆，左下保持方硬。
- 顶部使用朱砂短线与灵青短线作为“封印标记”。
- 面板内部保持统一网格，外部可以有少量墨渍溢出。

### 6.2 按钮

- 主行动：符金渐变、深色文字、灵青外发光。
- 次行动：墨绿底、灵青边界、浅色文字。
- 危险/结束回合：暗红底、朱砂边界。
- 按钮不做悬浮胶囊，保持“木牌/符令”质感。

### 6.3 卡牌

- 卡牌是玩家约束层的核心，必须保持同尺寸、同基线。
- 选中：灵青实线；待确认：符金实线。
- 稀有度只改变边框、角标和少量光晕，不改变卡牌尺寸。
- 卦名和卦力必须优先于装饰。

### 6.4 敌人与意图

- 敌人立绘/图标允许最“怪奇”，可使用暗红眼点、墨污、扫描线。
- 意图条必须独立、稳定、可读，不能放进墨渍背景里。
- 五行克制、状态层数、斩杀提示使用标签化信息，避免纯图标无文字。

### 6.5 坊市商品

- 商品区允许更杂乱：货架签条、红印、已售出斜纹。
- 价格与购买按钮固定在商品底部，不被装饰遮挡。
- 已售出商品降低饱和度和对比度，并保留“已售出”文字。

### 6.6 图鉴

- 8×8 矩阵是图鉴主结构，已发现与未发现必须一眼区分。
- 未发现格使用灰褐、斜向侵蚀、问号，不使用纯黑隐藏。
- 当前选中格使用灵青高亮，已精通使用符金星点。

### 6.7 修行路线

- 路线允许像墨迹或裂缝一样弯曲，代表世界不可控。
- 当前节点与“开始战斗”按钮必须保持约束层的高对比。
- 渡劫节点使用朱砂，普通节点使用符金，未解锁节点使用灰褐。
- 路线背景可出现墨池和扫描线，但节点文字不能被覆盖。

## 7. 动效规则

| 场景 | 动效 | 时长 |
|---|---|---:|
| 选中卦牌 | 灵青边缘点亮、轻微上浮 | 120~160ms |
| 合成卦象 | 内外卦向中间合拢、墨晕扩散 | 220~320ms |
| 伤害结算 | 数字短促放大、朱砂残影 | 160~240ms |
| 敌人意图 | 红色扫描线掠过一次 | 180~260ms |
| 解锁新卦 | 墨迹退去、六爻线显现 | 300~450ms |
| 错误/危险 | 1~2 次横向错位，不持续闪烁 | 100~160ms |

所有动效必须服务信息变化。禁止长时间循环闪烁、全屏故障和遮挡点击的动画。

## 9. Do / Don't

### Do

- 让玩家可控区域保持“秩序感”，让外部系统承担“污染感”。
- 用卦象线、册页水印和红印建立识别，而不是堆满古风纹样。
- 用低饱和色彩保证长时间阅读。
- 让危险、未知、失控只发生在玩家需要判断的位置。

### Don't

- 不要把所有界面都做成纯黑加金色。
- 不要让赛博元素变成霓虹科幻。
- 不要让微恐效果遮挡 HP、灵力、价格、意图和按钮。
- 不要用大量书法字体替代正文。
- 不要为了“水墨”牺牲 64 卦矩阵、手牌和数值比较效率。
